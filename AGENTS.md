# AGENTS.md instructions for `/workspace/dita-ot`

## Experiments
- Create an `experiments` folder where each experiment gets its own folder.
- In each experiment folder include:
  - a README explaining:
    - the goal
    - what worked
    - what didn't
    - what we could try further
    - an honest opinion on whether we are in the right direction
  - a fully reproducible setup including scripts and sample data.
- Include a `samples` folder where we check out the Oxygen XML user guide sources.

## Documentation
- Keep experiment-facing documentation in `docs/`.
- Prefer one overview document plus focused deep-dive documents for significant steps.
